## 2. 使用方式

```bash
# 自动验证（-p/exec 默认开启；交互模式用 --verify 显式开启）
# 首次使用先固化验证命令；未固化的仓库发现命令不会自动执行
syao verify init
syao -p "fix the failing test"
syao -p "fix the failing test" --no-verify
syao -p "check" --max-total-tokens 200000 --max-wall-clock-ms 600000

# 固化验证命令（团队真实门禁）
syao verify init
syao verify init --force

# JSON（schemaVersion 2）
syao -p "fix it" --output-format json
```

- `verified`：所有验证命令通过，且最终回复中的可检验声明都有**写操作之后**的回执支持。
- `unverified`：缺少验证、存在无回执/过期声明，或验证未跑；退出码 5。
- `verification_failed`：任一验证命令失败；退出码 6。
- 未发现验证命令时 `verdict = not_run`，不误报 verified/unverified。
